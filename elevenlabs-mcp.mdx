# ElevenLabs MCP Setup Guide

The hosted ElevenLabs MCP lets supported AI assistants call ElevenLabs creative tools directly, without running a local MCP server or pasting an API key into your client configuration.

## Hosted MCP endpoint

```text
https://api.elevenlabs.io/v1/mcp
```

## What you can use it for

- text-to-speech and voiceovers
- transcription
- dubbing and localization
- music and sound effects
- image and video generation
- voice and chat agents

## ChatGPT

1. Open ChatGPT settings and enable Developer Mode.
2. Add a new plugin.
3. Select OAuth authentication.
4. Use the hosted MCP endpoint above.
5. Complete the ElevenLabs authorization flow.

## Claude

Open the connectors directory, choose ElevenLabs, and complete OAuth authorization.

## Cursor

Add the hosted endpoint as an MCP server in Cursor settings, then complete OAuth authorization.
