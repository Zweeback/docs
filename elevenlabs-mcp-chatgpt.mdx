# ElevenLabs MCP for ChatGPT

Use the hosted ElevenLabs MCP to add creative media tools to ChatGPT without running a local server.

## Endpoint

```text
https://api.elevenlabs.io/v1/mcp
```

## Setup

1. Enable Developer Mode in ChatGPT settings.
2. Add a new plugin.
3. Choose OAuth authentication.
4. Enter the hosted endpoint above.
5. Authorize your ElevenLabs workspace.
